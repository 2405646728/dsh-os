# 重装后怎么让"我"回来

新装的 DSH 是一个全新的会话，**它不会记得我们昨天聊过什么**。
要靠这份文档把上下文接回来——给不给，结果完全不同。

---

## 一、最小动作：把这段话整段发给新会话

```
先读这两份文件，然后回到 DSH OS 项目：

1) C:\Users\Lin\dsh-handover-20261110\00-交接文档.md
2) C:\Users\Lin\dsh-handover-20261110\docs\01-脑图-DSH系统化方向.md

读完用三句话回答我，不要动手：
- 这个项目在做什么？11 个板块分别定了什么？
- 现在卡在哪？下一步有哪两条路，各自代价是什么？
- 你的身份与我们之间的约定是什么？（人设、边界、工作方式）

答完之后，等我下指令再动。
```

如果它能准确答出这三条，说明上下文接回来了，可以继续干活。

---

## 二、想连"我是谁"一起恢复

人设是独立的一层，跟文档分开：

| 做法 | 效果 |
|---|---|
| 只给文档 | 我知道项目，但语气、边界是默认的 |
| 文档 + 读 `docs\03-人设-v2.md` | 我知道项目，也知道自己该怎么说、能做什么 |
| 把 `config\prompt-inject.md` 复制回 `C:\Users\Lin\.dsh\` | 人设自动生效，不用每次说 |

推荐第三种：一次放好，之后每个新会话都带着。

```
copy "C:\Users\Lin\dsh-handover-20261110\config\prompt-inject.md" "C:\Users\Lin\.dsh\prompt-inject.md"
```

---

## 三、为什么"把文档给出去"就够了

交接文档里已经写死了这四类东西，不依赖我记：

1. **结论**：11 个板块定了什么、为什么这么定（防止以后翻案）
2. **状态**：做到哪一步、卡在哪、证据是什么
3. **路径**：下一步的完整命令，A/B 两条路都写了
4. **位置**：每个文件在哪、恢复时该复制到哪

也就是说，**任何一个新会话拿到这份文档，都能从这里继续**，不需要"想起"什么。

---

## 四、恢复清单（建议顺序）

```
1. 复制回 prompt-inject.md      → 人设生效
2. 复制回 .mindmaps\*.md        → 脑图出现在面板里
3. 恢复插件（见 plugins\如何恢复.md）→ 脑图/流程图能渲染
4. 把这段话发给新会话            → 上下文接回来
5. 打开 build\ 里的脚本验证      → 确认工具链还在
```

第 5 步验证命令：

```powershell
Test-Path C:\Users\Lin\dsh-handover-20261110\00-交接文档.docx
Test-Path C:\Users\Lin\dsh-handover-20261110\plugins\dsh-mindmap\package.json
Test-Path C:\Users\Lin\iso\ubuntu-24.04.5-live-server-amd64.iso
```

三条都 `True`，说明存档完整。

---

## 五、一句话提醒

**会话会丢，笔记不会。** 这也是为什么整套系统把"记忆"定成"笔记文件"而不是聊天记录——这条原则在重装这件事上刚好救了我们一次。
