# 插件恢复（dsh-mindmap / dsh-mermaid）

重装 DSH 后，插件默认不在了。`plugins\` 里放的是**当前能跑的完整包**，可以直接复制回去，不用联网装。

| 包 | 版本 | 大小 | 作用 |
|---|---|---|---|
| dsh-mindmap | 0.18.6 | 0.4 MB | md 文件即脑图，右侧面板实时跟随 |
| dsh-mermaid | 0.4.5 | 3.4 MB | 把 ```mermaid 代码块渲染成图 |

---

## 方法一：手工复制 + 注册（推荐，不走 pnpm）

之前用官方安装器踩过坑：`EPERM: operation not permitted, rename 'lightningcss-win32-x64-msvc'`——因为运行中的应用锁住了原生模块。手工复制能绕开。

### 1. 复制包

```powershell
$nm = "C:\Users\Lin\.dsh\profiles\desktop\node_modules"
Copy-Item "C:\Users\Lin\dsh-handover-20261110\plugins\dsh-mindmap" "$nm\dsh-mindmap" -Recurse -Force
Copy-Item "C:\Users\Lin\dsh-handover-20261110\plugins\dsh-mermaid" "$nm\dsh-mermaid" -Recurse -Force
```

### 2. 注册到 profile

编辑 `C:\Users\Lin\.dsh\profiles\desktop\package.json`，两处：

```jsonc
{
  "dependencies": {
    // 按字母序插进去
    "dsh-mermaid": "0.4.5",
    "dsh-mindmap": "0.18.6"
  },
  "dsh": {
    "profile": {
      "bundles": [
        // ……原有内容……
        "dsh-mindmap",
        "dsh-mermaid"
      ]
    }
  }
}
```

### 3. 重启 DSH

完全退出应用再打开（不是刷新页面）。

### 4. 验证

- 脑图：把 `docs\01-脑图-DSH系统化方向.md` 放回 `C:\Users\Lin\.mindmaps\`，面板里应能打开
- 流程图：随便发一句带 ```mermaid 代码块的消息，能出图就是活的

---

## 方法二：从应用市场装

新版 DSH 如果有插件市场入口，直接搜 `dsh-mindmap` / `dsh-mermaid` 安装即可，比手工注册省事。

**注意**：如果安装时报 `EPERM ... lightningcss`，说明应用正在运行并锁住了原生模块——先完全退出 DSH，再装；或者退回方法一。

## 方法三：全新获取（包丢了的情况）

```powershell
# 直接下载 tarball，不经过 pnpm
curl.exe -L -o "$env:TEMP\mm.tgz" "https://registry.npmjs.org/dsh-mindmap/-/dsh-mindmap-0.18.6.tgz"
curl.exe -L -o "$env:TEMP\me.tgz" "https://registry.npmjs.org/dsh-mermaid/-/dsh-mermaid-0.4.5.tgz"
tar -xzf "$env:TEMP\mm.tgz" -C "$env:TEMP\dsh-mm"
tar -xzf "$env:TEMP\me.tgz" -C "$env:TEMP\dsh-me"
# 然后把解压出来的 package 目录复制进 node_modules，再走方法一的第 2 步
```

---

## 一个容易踩的点

`dsh-mermaid` 的 `cordis.patch.yml` 会往插件树里插一行 `id: ui-mermaid`；`dsh-mindmap` 插的是 `id: mindmap`。
如果启动后报"row already exists"，说明 `package.json` 里那个 bundle 名重复了，删掉多余的那一个即可。
