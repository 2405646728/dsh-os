## 已定（一句话一览）

- 2 运行时：systemd --user + linger（host 先起）；端口 8787 + flock；崩了秒级重启、5 次停手、续跑；journald + 文件双写；升级双副本
- 3 界面：顶栏横跨整宽 + 左导航七页 + 主区 + 右侧双卡 + 底部三卡 + Dock 八格；大时钟 + 农历

- 5 权限：bwrap + sudo 白名单 + cgroup；日限 20 元；危险动作有人点确认、无人排队；审计 30 天
- 6 总账：sqlite 明细 + 每日 md 摘要；可导出
- 7 镜像：先只做 VM 镜像；安装器 autoinstall + 定制 slideshow
- 8 风险：VM 分 8GB；认准 Samsung 盘；快速启动必关；保留 Windows 三个月
- 9 人设：默认名字大肥鱼、可对话改名；直接冷静；全自主含联网；只记决定与产物；失败先自修限 2 次；边界三条
- 10 装机助手：.NET8 + WebView2；认机器→体检→BIOS 四层指引→下官方镜像→写盘；只认可移动盘 + 手输盘符

## 11 内置小模型（定稿）
- 定位：只做兜底——对话、解释报错、带首次设置向导、系统自检；不干重活
- 选型：Qwen 系 1.5B（Q4 约 1GB，中文最好）
- 引擎：llama.cpp 的 llama-server，暴露 OpenAI 兼容端点
- 进程：systemd --user 服务（llama.service），端口 8081，与 DSH 的 8787 分开
- 交付：权重烘进镜像（镜像 +1GB），保证装完即用、断网可用
- 切换：配好 key 后默认走云端；断网 / 超时 / 额度用完 → 自动降回本地
- 边界：**不参与自动任务判断**（目录监听、定时、飞书一律走云端），避免误触发
- 内存预算：常驻 ≤1.6GB
